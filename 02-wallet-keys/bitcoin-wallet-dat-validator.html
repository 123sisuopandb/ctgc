18. Bitcoin Wallet Dat Validator

Instructions:
Select a wallet.dat file using the 'Choose File' button, then click Process. The tool will parse the Berkeley DB, extract the Master Key Hash (JTR format), and list all encrypted private keys mapping to their Bitcoin addresses.
